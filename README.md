# yianmei

将遗失的编织成完整 · weaving the lost into something whole. Live: https://keeonho.github.io/yianmei/

Intro site for dorm Yianmei: Chinese teens from Chengdu who love thrifting. Muse: Jeong Ian (Hearts2Hearts).
Sections: poster hero, a receipt that prints as you scroll, the rack (every member as a thrift tag that swings), a draggable photo haul, and a stitched outro.

One `index.html` with GSAP (ScrollTrigger, Draggable) and Lenis from CDN.
